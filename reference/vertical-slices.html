Vertical slices i metody rozszerzające

Ściąga do druku. Oparta na Vertical Slice Architecture i Extension Methods (C# Programming Guide); struktura i komunikaty błędów zweryfikowane na .NET 10.0.400.

Ćwiczone w lekcji 0004.

Metoda rozszerzająca — trzy warunki

public static class TicketsFeature          // 1. klasa static, nieogólna
{
    public static RouteGroupBuilder MapTickets(  // 2. metoda static
        this IEndpointRouteBuilder app)            // 3. this przy 1. parametrze
    { … }
}

W miejscu użycia potrzebny jest jeszcze using namespace'u, w którym leży klasa. app.MapTickets() kompiluje się do TicketsFeature.MapTickets(app) — cukier składniowy, rozwijany w czasie kompilacji.

Diagnostyka

KomunikatPrzyczyna

CS1061 — „X nie zawiera definicji Y… czy nie brakuje dyrektywy using”brak using namespace'u albo zgubione this
CS0246 — „Nie można znaleźć nazwy typu”typ z innego namespace'u bez using

Wzorzec pary Add* / Map*

public static IServiceCollection AddTickets(this IServiceCollection services)
{
    services.AddSingleton<ITicketStore, InMemoryTicketStore>();
    return services;                     // zwróć argument → łańcuchowanie
}

public static RouteGroupBuilder MapTickets(this IEndpointRouteBuilder app)
{
    var tickets = app.MapGroup("/tickets").WithTags("Tickets");
    …
    return tickets;
}
  • Add* woła się przed builder.Build(), Map* po. Kontener zamyka się w Build().
  • Bierz IEndpointRouteBuilder, nie WebApplication — wtedy feature podłączysz też pod grupę: app.MapGroup("/api").MapTickets().
  • Zwracanie argumentu nie jest wymagane, ale daje ten sam styl co wbudowane Add*.

Slices vs Clean Architecture

Vertical slicesClean Architecture
Podziałpo featurepo warstwie
Nowy featurejeden folder, zero zmian w istniejącychplik w każdej warstwie
Zależnościslice nie zna slice'uwszystko wskazuje do środka
Cenaduplikacja między slice'amiabstrakcje, skakanie po projektach

Nie są alternatywami — slices bywają wewnątrz warstwy Application. Hasło do zapamiętania: „Minimize coupling between slices, and maximize coupling in a slice.”
