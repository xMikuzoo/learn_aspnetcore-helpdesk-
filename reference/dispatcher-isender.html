Dispatcher / ISender

Ściąga do druku. Nazwy MediatR wg MediatR Wiki; kod i komunikaty błędów zweryfikowane na .NET 10.0.400.

Ćwiczone w lekcji 0006.

Trzy kawałki

public interface ICommand<TResult>;                // marker: niesie typ wyniku
public interface IQuery<TResult>;

public interface ICommandHandler<in TCommand, TResult>
    where TCommand : ICommand<TResult>   // spina command z wynikiem
{
    Task<TResult> HandleAsync(TCommand command, CancellationToken cancellationToken = default);
}

public interface ISender
{
    Task<TResult> Send<TResult>(ICommand<TResult> command, CancellationToken cancellationToken = default);
    Task<TResult> Send<TResult>(IQuery<TResult> query, CancellationToken cancellationToken = default);
}
Po co marker. W miejscu wywołania kompilator widzi tylko argument. Marker zapisuje typ wyniku w typie commanda, więc await sender.Send(new GetTicketQuery(5)) ma typ TicketDto? bez podawania czegokolwiek ręcznie.

Rdzeń: refleksja

public class Sender(IServiceProvider provider) : ISender
{
    public Task<TResult> Send<TResult>(ICommand<TResult> command, CancellationToken ct = default) =>
        Dispatch<TResult>(typeof(ICommandHandler<,>), command, ct);

    private Task<TResult> Dispatch<TResult>(Type openHandlerType, object message, CancellationToken ct)
    {
        var handlerType = openHandlerType.MakeGenericType(message.GetType(), typeof(TResult));
        dynamic handler = provider.GetRequiredService(handlerType);
        return handler.HandleAsync((dynamic)message, ct);
    }
}
ElementZnaczenie
typeof(IHandler<,>)otwarty typ generyczny — szablon bez wypełnionych parametrów
MakeGenericType(a, b)wypełnia szablon, zwraca Type do zapytania kontenera
message.GetType()konkretny typ commanda, niedostępny przy kompilacji
dynamicwyłącza kontrolę typów w tej linii; metoda szukana po nazwie w runtime

Rejestracja i użycie

services.AddScoped<ISender, Sender>();                                   // Scoped, nie Singleton
services.AddScoped<ICommandHandler<CreateTicketCommand, TicketDto>, CreateTicketHandler>();

public record CreateTicketCommand(string Title) : ICommand<TicketDto>;

var ticket = await sender.Send(new CreateTicketCommand(request.Title), cancellationToken);

Request (kontrakt HTTP) markera nie dostaje — o dispatcherze nie wie nic.

Service locator. Kontener widzi w konstruktorze Sender tylko IServiceProvider, więc walidacja w Build() nie sprawdzi, czy handlery istnieją. Część błędów przenosi się ze startu na pierwsze żądanie. Łagodzenie: auto-rejestracja przez skan assembly albo test integracyjny po wszystkich trasach.
